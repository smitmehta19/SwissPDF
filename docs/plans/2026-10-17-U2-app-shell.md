# U2 App shell redesign: scope

Status: APPROVED (part of the approved parity plan), starts after U1 integration. Parent: `2026-10-17-parity.md`.
Design sizing (design-master): **redesign of an app shell** = full flow, steps 0-14. Tokens exist (iris palette, system font stack, mono for measurements), so steps 4-5 extend the existing tokens rather than replace them.

## Phase U2a: direction + shell + contracts (1 dev, Opus)
- Steps 0-6: read current `src/styles.css`, `App.jsx`, research files; write `docs/design/DESIGN.md` (Design Read, direction plan, layout ASCII, tokens: colour light/dark, type scale, spacing, radius, shadow, z-index, motion). Stirling-style workbench, iLovePDF option patterns, own brand.
- Build (steps 7-9):
  - `src/app/fileStore.js`: app-level files in IndexedDB (blob by reference), versions per file (`parentId`, `toolHistory`), wipe-all button, quota handling, works when IndexedDB is unavailable (memory fallback).
  - `src/app/jobs.js`: job runner with progress (done/total), cancel (AbortSignal checked per page), pdf-lib + MuPDF ops in a Web Worker where the op is pure bytes-in/bytes-out.
  - Shell: top bar (search "/", theme toggle), left tool panel (categories, search, favourites, recent), centre workbench with modes: file grid (rotate, remove, sort by name/size/date, add files tile, drag reorder), viewer, page editor (multi-file tracks, rotate/delete/duplicate/insert blank, select by range, undo), right options panel (sticky Run button, live "N files will be created" line), result screen (preview, download, "continue with another tool", start over, undo to previous version), unsaved-work guard, Esc only closes dialogs.
  - Tool contract: `{ id, name, io, category, icon, accepts, Options (component), run(files, options, ctx) -> outputs }` with `ctx.progress`, `ctx.signal`. Migrate 3 reference tools (merge, compress, watermark) to prove it.
- Out: migrating the other tools (U2b).

## Phase U2b: migrate all tools (4 devs in parallel, by tool group, non-overlapping files)
- Organize group, Optimize + Security group, Edit group (canvas tools: edit, sign, crop, redact, forms keep their own canvas inside the workbench viewer), Convert group.
- Each tool: Options panel uses captioned option cards / 3x3 position grid / live output line per iLovePDF patterns and option sets in `docs/research/ilovepdf-rea.md`.

## Review (separate agents)
- Steps 10-11: ux-copy pass + accessibility audit (WCAG 2.2 AA).
- Step 12: Playwright screenshots phone + desktop, light + dark, reduced motion; Lighthouse.
- Step 13: fresh critique agent (design-critique, impeccable critique/polish, review-animations, code-review), one fix batch, one confirm round.
- Corpus runner: UI intake + flow layers updated to the new shell and green; ops layer unchanged.

## Done when
- Every tool runs inside the new shell; files carry over between tools and survive reload; chain merge -> compress -> protect without re-adding files.
- Cancel works on OCR, compress, PDF->Word; progress shows on every multi-page op.
- Critique must-fix list empty; no serious/critical a11y findings; mobile works without horizontal scroll.
- Corpus runner green on everything that was green after U1; Health check green in dev and built app.
