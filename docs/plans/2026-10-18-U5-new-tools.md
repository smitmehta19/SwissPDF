# U5 New tools for parity: scope

Status: APPROVED (part of the approved parity plan). Starts after integ-1 + G2 are merged. Rows = `docs/plans/parity-checklist.md` "missing". Every tool on the tool contract (`docs/design/tool-contract.md`), options per Stirling/iLovePDF research, corpus cases on real files.

| Group | Tools | New lib (owned) |
|---|---|---|
| U5-A Page layout | N-up (2/4/6/9/16, order, border, margins), booklet (spine, gutter, duplex), overlay PDFs (sequential/interleaved/fixed repeat, fore/background), scale / page size (A-sizes, Letter, Legal, factor, fit), single large page, stamp (text/image, 3x3 grid, margin, opacity, rotation, page selection), remove blank pages (threshold, white %), linearize (fast web view) | `src/lib/layoutOps.js` |
| U5-B Structure + cleanup | Bookmarks / TOC editor (tree edit, add from headings), metadata editor (all Info + XMP, delete all), attachments (add/list/extract/remove), remove annotations, remove images, sanitize (JS, embedded files, XMP, metadata, links, fonts), flatten (forms only / full), change permissions (8 flags), PDF info (fonts, images, forms, encryption, JS, per-page), auto rename (first heading) | `src/lib/docOps.js` |
| U5-C Convert extra + colour + capture | TXT / Markdown / RTF / ODT / CSV to PDF (engine for rtf/odt/csv, md via HTML path), PDF to text / HTML / CSV / EPUB, PDF to PDF/A (Ghostscript WASM, AGPL OK; validate basics: XMP pdfaid, OutputIntent, fonts embedded), adjust colours / invert / grayscale / high contrast, scan to PDF (camera capture, corner crop, enhance, multi-page), auto rotate (OSD from OCR worker) | `src/lib/convertExtra.js`, `src/lib/colorOps.js`, `src/lib/pdfa.js` |
| U5-D Advanced | Edit existing text (MuPDF: find span, replace with matching font size/colour, reflow within the line; Latin first, others where font covers), certificate sign (PKCS#12 import, visible stamp, PAdES-B detached via pkijs) + validate signature, Automate (saved ordered tool chains with saved options, run on many files, stored locally) | `src/lib/textEdit.js`, `src/lib/certSign.js`, `src/app/automate.js` |

Rules: one dev per group, owned files only; registry entries in `src/tools/v2/group-<name>.js`; shell changes minimal and listed; orchestrator merges shared files.
Done when: every row green on real corpus files (outputs reopen in pdf.js + MuPDF, content checks), no PASS->FAIL vs integ-1, Health green dev + build, parity checklist rows updated.
