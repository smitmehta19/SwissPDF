# U5-A review: page layout + colour tools

Reviewer: independent QA. Date: 2026-10-26/27. Worktree `agent-a29ce0a796c2d9627`, uncommitted change on top of `09146c6`.
Scope: `src/lib/layoutOps.js`, `src/lib/colorOps.js`, `src/tools/v2/{nup,booklet,scale,singlepage,stamp,removeblank,overlay,layoutShared,adjustcolors,replacecolors,linearize}.jsx`, `group-layout.js`, `scripts/corpus-test/{cases-u5a.mjs,page-harness-u5a.js,lin-check.mjs,u5a-ui.mjs}`, registry / harness / cases edits, plus the unrelated `src/lib/imageOps.js` edit.

## Verdict

**Approve with fixes.** The claimed numbers hold: 61/61 corpus rows, build, UI flows, no network, correct geometry on rotated / CropBox / moved-origin pages, and a linearize writer that is structurally sound on 109 of 110 readable corpus files. Two P1s must be fixed before the parity rows go green:
1. Imposition tools (N-up, booklet, Page size, plus overlay's overlay pages) silently drop filled form values, comments, links and bookmarks.
2. Fast web view makes object-stream PDFs up to 4.5x bigger, and slower to show page 1 in pdf.js.

P0: 0. P1: 2. P2: 7. P3: 6.

## Not verified

- qpdf `--check-linearization` / Acrobat "Fast Web View: Yes": qpdf is not installed and no packages were installed (pikepdf would bundle qpdf). Covered instead by reading the spec, lin-check with mutation tests, third-party linearized files, and pdf.js ranged loading.
- Physical duplex print for the booklet flip (#5). Reasoning only.
- pdf.js rendering of invert / high contrast on a page without Contents (#4). Only MuPDF was checked.
- Viewers without blend-mode support (#14): Acrobat, macOS Preview, mobile viewers, print RIPs.
- Files over 20 MB (`large/`, darwin scan) through linearize, N-up and colour tools. Memory not profiled beyond llama2 and us-budget.
- Cancel mid-op in the UI. Inferred from code: no worker, and `ctx.check` is only called between pages.
- Stamp image path with JPEG / WebP uploads through the UI (the corpus row uses a generated PNG).
- Booklet "backs only" stack order for manual duplex on real printers.
