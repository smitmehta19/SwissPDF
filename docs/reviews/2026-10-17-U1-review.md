## Verified OK (with evidence)

- **Build**: `npm run build` OK. fontkit is its own lazy chunk (579 kB).
- **Corpus (quick, 4 shards, `docs/test-results/review-U1.md`)**: 91 pass, 5 fail. All 5 fails are already listed as U3/U4 in the U1 scorecard (excel2pdf, heic, tiff, redact-rot90, compare-inserted). No new failures.
- **Health on the production build under /SwissPDF/** (`serve-pages-sim.mjs` + `health.mjs --url`): 44 of 44.
- **Intake error paths** (Node, normalizePdf), each tested with no password, a wrong password and the right one:
  - issue6010_1/_2, issue21579 and saslprep-r6: NEEDS_PASSWORD, then WRONG_PASSWORD, then accepted with the "Password removed" notice. No loop.
  - pdfjs-Pages-tree-refs: repaired, 1 page, which matches TRUE_PAGES.
  - The intake page count matches MuPDF for every corpus file, apart from the 2 MuPDF 0-page files (correctly rejected) and tree-refs.
- **Password UI on the built app**: prompt appears; a wrong password shows "Wrong password, try again." and keeps the prompt; the right one gives "1 page" plus the notice; merge with the unlocked file downloads.
- **Outline / dests / labels** (synthetic file with a /Next cycle, a /First self-cycle, no /Parent anywhere, a named string dest, a numeric GoTo dest and page labels i,ii,5,6):
  - Remove, split and self-merge all give correct bookmarks and targets.
  - Renamed named dests resolve to the second copy.
  - Labels are kept.
  - No hang on the cycles.
- **Merge IRS fw9 + f1040sa**: 56 fields, all names unique. A widget from a part-2 field sits on page 7 of 7. Fill plus save works.
- **Split fw9**: fields stay on the part that holds their widgets. Extracting page 24 of i-485 gives a small output (118 objects): pruned fields do not bloat it.
- **pageFrame vs pdf.js viewport**: 30 synthetic pages (rotation 0/90/180/270/-90/450 x negative-origin MediaBox, offset CropBox, flipped MediaBox, CropBox outside MediaBox). Size and 4 sample points match pdf.js `convertToViewportPoint` within 0.01 pt, 0 mismatches.
- **Privacy / network** (built app, Playwright request log):
  - No off-origin requests for watermark with CJK text, nor for loading the noembed-sjis + JPX files.
  - Fonts load from `/SwissPDF/fonts/...`.
  - pdf.js loads cmaps (`90ms-RKSJ-H.bcmap`, `Adobe-Japan1-UCS2.bcmap`) and `wasm/openjpeg.wasm` from `/SwissPDF/pdfjs/`.
  - No new console logging of document data in the diff.
- **Large files** (built app):
  - 956 p / 62 MB: intake 0.9 s; first 100 page previews in 119 s (slow, about 1.2 s per page); split 1-400 / 401-956 in 8.4 s; heap 81 MB; no crash.
  - 585 p: 100 previews in 2.1 s.
  - Organize (not a U1 file) renders all 956 thumbnails before showing anything: nothing shown after 5 min (audit #34, U3).
- **Runner spot checks** (5 cases read against their validate code):
  - c-crop: hard CropBox check is sound.
  - c-edit: exact origin and image box, hard.
  - intake rows: page count, notice and prompt checked.
  - merge-outlines/forms: soft, count only (finding #4).
  - c-*-text: accepts reversed strings (finding #3).
  - Example of a wrong pass: ar-mixed would pass with "4202".
