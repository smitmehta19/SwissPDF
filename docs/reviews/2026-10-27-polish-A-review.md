# Review: polish batch, group A (shell + flow), 2026-10-27

Reviewer: independent QA, read-only on src/ and scripts/. Diff reviewed: `git diff HEAD` (HEAD = 93290a6) on the Group A files, plus the orchestrator's restriction hooks in Shell.jsx/fileStore.js (checked only for impact on Group A behaviour).

## Verdict

**Reject until F1 and F2 are fixed (one shared cause; then approve with fixes).** The no-op rule (an output byte-equal to its input is dropped) breaks Auto rename completely (u5b-ui 3/3 autorename rows fail) and turns Unlock into a no-op for files whose protection was removed on add (a card-unlocked file can never be kept unlocked, and owner-only restrictions can no longer be removed: later outputs stay restricted). The chain-name fix (blind P2 6) does not fix the blind reviewer's own repro: from the third tool on, names grow again. Everything else claimed checks out or has only minor issues.

Counts: **P0: 0, P1: 2, P2: 2, P3: 8**
