Reviewer: independent QA, read-only on src/ and scripts/. Engine probed directly in Node (mupdf 1.28, the same `editTextOps.js` the worker loads, fetch stubbed to `public/fonts`). Probe scripts and outputs are in the review session scratchpad `C:/Users/SMITME~1/AppData/Local/Temp/claude/C--Users-Smit-Mehta-OneDrive---SalesOptimize-Desktop-Data-Code-r-NEwCOde-ClaudeCode-SwissPDF/af85e6f0-a1c0-412d-bfc1-0d9738bfa4dd/scratchpad/` (session-only; the P0 fixtures are inline below so they can be rebuilt) (`p1.mjs`, `mk1.mjs` to `mk5.mjs`, `ed.mjs`, `perf.mjs`; files `syn1.pdf`, `syn2.pdf`, `syn3.pdf`, `o-*.pdf`, `*.png`). Note: `editTextOps.js` changed during the review (`ms.total` appeared); findings are against the copy on disk on 2026-10-28 around 01:00 to 02:00.

## Verdict
**Reject for deploy as is.** 2 P0, 3 P1. The engine is solid on the happy path (rotation, CropBox, shared XObjects, same word twice, punctuation all fine), but the two worst failure classes from the brief both reproduce: old text stays in the file (ActualText), and a pushed line reveals text a white box was hiding. Neighbour-line text can also be deleted silently on tight leading.

## Verified OK (with evidence)
- Same word twice on a line: `syn1` "the cat and the dog and the end", word 3 to "THE": only the second "the" changed.
- Apostrophe, quotes and underscore inside an edited word are fully removed (`o-A.png`: "Don't", "'quoted'", "user_name" replaced cleanly, no floating marks).
- Shared Form XObject on pages 1 and 2: editing page 1 left page 2 "Shared header ACMECORP here" intact (`syn2`, `o-C.pdf`).
- Rotate 90/180/270 with an offset CropBox, horizontal and sideways lines: 0 px changed outside `changedBox` on all three pages (`syn3`).
- Delete (empty text) applies with `font: null`; the rest of the line does not move.
- Render mode 3 text is marked `hidden` and not editable (`syn1` "InvisibleWord").
- Line spacing of 1.0 em and more: neighbour lines untouched (Helvetica, Times, Courier, Noto Sans; `mk2.mjs`, `mk3.mjs`).
- Outputs reopen in MuPDF (us-budget: 184 pages after an edit).
- Restricted inputs: `edit` is not in `OWN_RESTRICTIONS` (`src/lib/intake.js:172`), so Shell `run` (`Shell.jsx:648`) re-applies the permission flags to the Edit output. Code read only.
- Stale run ids after undo/redo: every UI edit passes `old` (`edittext.jsx:401`) and the engine refuses a mismatch as `stale` (`editTextOps.js:882`). Code read.
