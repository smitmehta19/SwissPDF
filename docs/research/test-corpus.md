# SwissPDF real-world test corpus

Folder: `test-corpus/` (gitignored). Rebuild with `bash scripts/fetch-test-corpus.sh` (idempotent, skips existing files; Wikimedia Commons rate limits, so re-run if some fail).
All files are real third-party files, downloaded unmodified. Treat as untrusted: never open or execute from inside the folder with interpreters.
Files: 131. Total: 352.1 MB. Per category: forms 13, scanned 8, reports 11, large 4, intl 12, quirks 50, invoices 10, office 12, images 11.
sha256 column shows the first 12 hex chars. Page counts were not collected (no safe tool run); see sizes.

Passwords: from pdf.js test/test_manifest.json. pdf.js manifest has no owner-only password for empty_protected.pdf; open with empty user password.

## Known gaps
- No phone photo of a document (no freely licensed file found).
- No verified skewed scan (scanned/ files are archive scans; skew not measured).
- No real payslip or bank statement with a clear open licence; invoices/ holds real vendor invoices from the invoice2data MIT test set only.
- No dedicated owner-password-only PDF with a known owner password.
- Page counts not recorded.
